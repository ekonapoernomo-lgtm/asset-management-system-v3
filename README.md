\# Asset Management System V3

Asset Management System V3 adalah aplikasi manajemen aset berbasis Python dan SQLite yang memungkinkan pengguna untuk mengelola data aset melalui menu command line interface (CLI).

\## Features
\- Add Asset
\- View Asset
\- Update Asset Condition
\- Delete Asset
\- Search Asset
\- SQLite Database Integration

\## Tech Stack
\- Python 3
\- SQLite
\- Git

\## Project Structure
asset-management-system-v3
├── main.py
├── asset.py
├── db.py
├── asset.db
└── README.md

\## Database Schema
Table: aset
\- id
\- kode
\- nama
\- lokasi
\- kondisi
